# CODE-SAFE-VACCINE

Open-source framework for predicting PEG-LNP anaphylaxis risk and
first-in-human (FIH) dose optimization.

Companion code for:

- **Article 5A** — *Open-Source Framework for Predicting PEG-LNP
  Anaphylaxis Risk: Linking Published In Vitro and In Vivo Data to
  First-in-Human Dose Optimization* (Bioinformatics, submitted)
- **Article 5B** — *PGL-LNP vs PEG-LNP for mRNA Vaccines: A 64-Fold
  Wider First-in-Human Safety Window Predicted by Provenance-Validated
  Monte Carlo Dose Optimization* (Vaccines, submitted)
